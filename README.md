# AI Food & Activity Coach

A web app that shows the estimated calories of everyday Malaysian food, suggests lighter choices and activity ideas, and teaches balanced eating through a nutrition quiz.

- `index.html`: English version
- `bm.html`: Bahasa Melayu version

## Features
- 85 Malaysian foods and drinks, with servings
- Add foods that aren't on the list (estimate by type or manual entry)
- Meal analysis: calorie ring, breakdown, smart tips and lighter swaps
- Activity suggestions from light to vigorous
- Nutrition quiz with past records
- Dark mode and phone-friendly layout

Calorie values are estimates based on MyFCD, KKM, USDA FoodData Central and the Compendium of Physical Activities. Not a substitute for professional health advice.
